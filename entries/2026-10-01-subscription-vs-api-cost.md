# What AI coding subscriptions are worth at API prices

**X post:** https://x.com/PawelHuryn/status/2105703147184239042  
**Author:** Paweł Huryn (@PawelHuryn) · posted 2026-10-01 (UTC) · 823 likes, 111 replies  

## What it is
@PawelHuryn burned part of the weekly allowance on several plans, logged each call and priced it at public API rates. Per vendor statements, OpenAI's allowance scales linearly with price (Pro 200 now 10x, down from 20x), while Claude Max 20x ($200) gives 20x Pro and so is subsidised about twice as much; Meta Muse Code tiers are similar. His thread argues that despite Anthropic's bigger multipliers, GPT-6.1 Sol still costs less than Opus 5.5.

## Implications
- Useful for choosing a plan mix: Claude Max 20x is the most subsidised for heavy Blender/Unity agent sessions, but routing cheaper tasks elsewhere may lower total cost.
