# Leviathan: agents search huge databases in ~436 tokens

**X post:** https://x.com/joshuagunnn/status/2107108554192941493  
**Author:** joshua (@joshuagunnn) · posted 2026-10-05 (UTC) · 2626 likes, 87 replies  

## What it is
@joshuagunnn open-sourced Leviathan (github.com/elstongun/leviathan), an indexer that lets agents search a database of any size without reading it. Claimed: at 1M records the agent gets 436 tokens instead of 107,000, with ~99% answer accuracy (author's numbers).

## Implications
- Could index a game's asset catalogue so agents find the right prefab without dumping folders into context.
- **Experiment:** index an asset list (names, tags, paths) and test whether an agent finds the right asset for 10 queries.
