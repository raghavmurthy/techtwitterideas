# Skill Issue: agent skills ranked by what people actually use

**Link:** https://skill-issue.in/  

## What it is
A directory of agent skills (for Claude Code, Codex and similar) ranked by usage rather than hype: each card shows GitHub stars or install counts plus clicks on the site, a category and a one-line description. When fetched, the top entries were design skills (ui-ux-pro-max-skill, frontend-design, taste-skill), followed by browser automation (agent-browser), React/Next.js patterns, Tailwind design systems, accessibility, API design and Remotion best practices for programmatic video. Some cards are marked "unverified link", meaning the curator hasn't opened and checked them by hand, which is a useful honesty signal.

## Implications
- A quick way to see which skills are widely adopted before writing your own; the ranking shows design and frontend-taste skills dominate usage.
- Skills can carry instructions and scripts, so treat any listed skill as untrusted until you've read it, especially "unverified" ones.
- There's no game-dev, Blender or Unity category yet, which suggests a gap.
- **Experiment:** pick the top design-taste skill and the Remotion skill, read them first, then use them on a small devlog trailer and a game landing page; compare the output with and without each skill.
