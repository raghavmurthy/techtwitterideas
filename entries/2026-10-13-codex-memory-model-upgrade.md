# Codex memory: swap the default memory models in config

**X post:** https://x.com/daniel_mac8/status/2110015197255450694  
**Author:** Dan McAteer (@daniel_mac8) · posted 2026-10-13 (UTC) · 346 likes, 26 replies  

## What it is
@daniel_mac8 says Codex's memory feature uses GPT-5.6 Luna and GPT-5.6 Terra by default, and that the extraction and consolidation models can be changed in Codex's `config.toml` to newer ones (he names GPT-6 Luna for extraction and GPT-6.1 Sol for consolidation). He calls it a free quality upgrade; the post gives no benchmarks.

## Implications
- Memory quality matters most in long engine projects where an agent must remember scene layout, build quirks and conventions across sessions.
- Stronger consolidation models may cost more usage; the 'free' claim is unverified.
- **Experiment:** in a Unity or Blender-scripting repo, run a week with default memory and a week with the upgraded models, then compare how often you re-explain the same project facts.
