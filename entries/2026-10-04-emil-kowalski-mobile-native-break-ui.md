## What it is
@emilkowalski added two skills to his skills repo (github.com/emilkowalski/skills): /mobile-native makes web apps feel native (e.g. disabling hover on touch), and /break-ui stress-tests UI with long names, odd emails and long lists and then fixes it.

## Thread highlights
> **@doguapps:** /break-ui should honestly be a mandatory pre-commit hook everywhere. Clean work.

> **@repitcoach:** /break-ui is a great idea. Long names and odd inputs break more apps than anything clever. Does it try huge numbers too, like totals that overflow a card?

> **@IkonraStudio:** disabling hover on touch is such a small thing that makes it feel right

## Implications
- /break-ui transfers to game UI: localised strings, long usernames and large numbers break mobile layouts.
- **Experiment:** write an engine-flavoured break-ui skill that feeds long/locale strings into UI prefabs and screenshots the result.
