# How Railway grew via AI recommendations (AI SEO)

**X post:** https://x.com/irabukht/status/2110189752666440181  
**Author:** Ira Bodnar (@irabukht) · posted 2026-10-14 (UTC) · 1603 likes, 95 replies  

## What it is
Ira Bodnar (@irabukht), building Ryze AI and formerly at Exa and McKinsey per the X bio, breaks down how Railway reportedly went from $20M to ~$100M ARR in a year by treating AI recommendations as a growth channel. Points: Claude Code picks Railway for 82% of Python apps; 6,653 how-to pages for self-hostable tools; 127 framework deploy guides; comparison and migration pages against competitors; help docs rewritten for AI with an index file and plain-text versions; docs written for agents; plugins inside ChatGPT and Claude Code; one-command servers without signup; weekly changelogs since 2021; and a seven-person go-to-market team. The weakness: Claude Code picks Vercel for front-end apps.

## Implications
- Tools and engines that game devs choose are increasingly picked by agents; docs written for agents are now distribution.
- **Experiment:** ask three coding agents how to do a common task with a tool or asset you publish, and note whether they recommend it; then add an llms-style index and plain-text docs and re-test.
